# 🤖 Thư mục Quản lý Nhật ký Sử dụng AI (AI Assistance Logs)

> **Mục tiêu**: Đạt tối đa điểm tiêu chí **C6 (1.5đ - Development Process & AI Log)** và bảo vệ mã nguồn minh bạch trong buổi **Defense (2.5đ)**.

---

## 📌 Hướng dẫn cho từng thành viên:

1. Hàng ngày khi code có sử dụng AI (ChatGPT, Claude, Gemini, Copilot):
   - Mở file **Google Sheet chung của nhóm** và dán câu prompt, kết quả và cách bạn sửa code vào Tab của mình.
2. Cuối mỗi tuần (trước buổi họp Sprint hoặc trước Checkpoint):
   - Copy nội dung trong Google Sheet vào file `docs/ai-log/[MSSV]_ai_log.md` của mình.
   - Commit lên nhánh feature cá nhân:
     ```bash
     git add docs/ai-log/[MSSV]_ai_log.md
     git commit -m "[MSSV] docs(ai-log): update AI assistance log for week X"
     ```
